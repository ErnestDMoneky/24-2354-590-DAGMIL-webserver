What I learned:
I learned how to start a simple web server using Python's built-in http.server module and access it through a forwarded port in GitHub Codespaces. I saw that the server reads files fresh on every request, so editing my HTML and refreshing the browser showed changes immediately without restarting anything. Watching the server logs helped me understand how HTTP requests work — each page load showed up as a GET request with a 200 status code, meaning it was found and served successfully. Building multiple linked pages also showed me how navigation and relative file paths connect a website together. Overall, this activity gave me a hands-on sense of what happens behind the scenes every time a browser loads a webpage.
